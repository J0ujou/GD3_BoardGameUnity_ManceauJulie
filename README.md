# GD3_BoardGameUnity_ManceauJulie
Note d’intention Board Game

Le but de ce projet est de produire un jeu de type « jeu de l’oie », jouable à plusieurs joueurs sur un même écran (au moins 2 joueurs).
Le but de ce jeu est d’atteindre la case finale du plateau, tout en respectant la règle de déplacement du jeu de l’oie : si le résultat du lancer de dé est supérieur au nombre de cases manquantes, le joueur part en arrière du nombre de cases qui lui reste à parcourir.
Le contexte de la situation : plusieurs prisonniers tentent de s’échapper de prison, le but est de s’échapper le premier, sans se faire attraper définitivement par le gardien de prison.
Les joueurs sont les prisonniers. Le gardien est un pion qui avance de 1 à 2 cases tous les 3 tours
Certaines cases du jeu proposent des effets particuliers :
Cases positives :
•	+2 : le joueur avance de deux cases supplémentaires
•	Rejouer : le joueur relance son dé
•	Le raccourci (pont du jeu de l’oie) : reprise d’une case du jeu de l’oie, si le joueur tombe précisément sur cette case, il se dirige directement sur une autre case plus loin prédéfinie
Cases négatives :
•	Blocage : le joueur doit passer son tour
•	Croche-patte : le joueur recule de 2 cases
Case ravitaillement (boutique) :
•	Le joueur va pouvoir acheter des objets divers pour avancer plus vite ou embêter le ou les joueurs adverses :
o	Dé nombre pair
o	Dé de la fatigue a donné à l’adversaire se son choix qui le force a tirer un dé qui propose seulement des 0,1ou2
o	Autre idée à développer
Des cases minijeux diverses qui permettent de gagner « l’argent du jeu » (trouver un nom) pour acheter des éléments dans la boutique :
•	Jeu de cache-cache : les deux joueurs se cachent dans un lieu restraint et un gardien (IA) tente de les trouver dans le temps imparti (plus préciser)
•	Autre mini-jeu
Des quêtes :
Des cases demanderont au joueur des quêtes particulières afin de gagner de l’argent ou un bonus pour le joueur :
•	Le joueur doit effectuer un certain score au dé
•	Autres idées
